# CivicNex · Bengaluru CivicPilot frontend

React + TypeScript + Vite responsive interface.

```bash
npm install
npm run dev
```

Set `VITE_API_URL` in a local `.env` file if the FastAPI server is not at `http://localhost:8000`.

The dashboard and operational views read incident data from the backend; the neighbourhood map illustration is explicitly simulated.
